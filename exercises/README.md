# Independent exercises

Exercises should reinforce course concepts rather than reproduce every fill-in-the-blank task.

Suggested workflow:

1. Complete the relevant DataCamp lesson.
2. Close the lesson and implement the concept independently.
3. Change at least one input or requirement.
4. Consider a realistic failure case.
5. Run the code and record what you learned.
6. Keep credentials out of source code and commits.

Use descriptive filenames such as `01_first_api_request.py`. Add tests when the exercise has behavior worth validating.
